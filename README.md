# Retail Sales Analysis 📊

A data analytics project using **Python, SQL, and Power BI** to understand retail sales, profit, customers, products, and regions.

##  Objective

The goal of this project is to find:

* Which region has the highest sales
* Which category performs best
* Which products generate the most profit
* How sales change over time
* How discounts affect profit
* Which customers are most profitable

##  Tools Used

* **Python** – Data analysis and visualization
* **SQL** – Business queries and analysis
* **Power BI** – Interactive dashboard
* **Pandas & Matplotlib** – Data analysis and charts

##  Dataset

The dataset contains **1,000 retail transactions from 2023**.

It includes information about:

* Sales
* Profit
* Product
* Category
* Customer
* Region
* Quantity
* Discount
* Date

## 🔍 Analysis

### Python

Used Python to explore the data and create charts for:

* Sales by region
* Profit by category
* Monthly sales
* Discount vs Profit
* Top customers

### SQL

Used SQL to answer business questions about:

* Total sales and profit
* Top products
* Regional performance
* Category performance
* Monthly sales
* Customer performance
* Loss-making products

### Power BI

Created an interactive dashboard showing:

* Total Revenue: **$1.23M**
* Total Profit: **$214.24K**
* Profit Margin: **17.36%**
* Total Orders: **1K**
* Sales by Region
* Sales by Category
* Monthly Sales & Profit
* Product Performance
* Discount vs Profit
